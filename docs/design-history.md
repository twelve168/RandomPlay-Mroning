# 研发迭代史

> 从 v1 到 v5.2 共六个硬件版本的机械结构迭代，全程 4 个月、炸掉一块
> 开发板和两个舵机。记录于此供后来者避坑。

| 版本 | 核心方案 | 失败/改进点 |
|------|----------|-------------|
| v1 | 壁挂式 + 鱼线收拉 | 鱼线打结卡死电机，放弃 |
| v2 | 挂轨 + 橡皮筋压轮 | 拓扑问题：橡皮筋无法套住机身，打钉临时补丁；下压力仍不足 |
| v3 | 上下双组轮 | 修好橡皮筋装配问题，但整机仍跑不动 |
| v4 | 取消上下分区直挂轨道 | 摩擦不足 → 外挂配重；副轮成为支点让主轮悬空 → 去除全部副轮 |
| v5 | 去副轮 + 集成配重挂钩 | 可用，但切向力不足、有烧电机风险 → 改小主动轮直径 |
| v5.1 | 小直径主动轮 + 接线端子 | 长期在用的稳定版本 |
| v5.2 | Type-C 直供电版 | 为开源重构模型，全面适配小直径轮（本仓库发布版本） |

## 关键经验

1. **摩擦驱动本质是压力管理**：轮面压力（配重）× 摩擦系数（胶带）×
   切向力（轮径）三者耦合，单改一项会被另一项抵消。
2. **副轮不是越多越好**：多轮刚性结构在有高度差的轨道上反而把主动轮
   顶离接触面（v4 教训）。
3. **连续旋转舵机选小轮径**：扭矩恒定时切向力与轮径成反比，小轮径
   显著降低堵转烧电机风险。
4. **拓扑问题要早想清楚**：v2 的橡皮筋套不上机身本可在建模阶段
   用一次 mental paper prototype 排除。
