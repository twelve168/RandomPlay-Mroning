# 组装与装配指南

## 前置条件

- 已打印 [cad/RandomPlay-Mroning-v5.2.step](../cad/RandomPlay-Mroning-v5.2.step)
  对应的结构件（适配 **23 mm 以内宽的方形窗帘轨道**；圆轨或更宽轨道需自行改模）
- BOM 中全部物料（见 [bom.md](bom.md)）
- 电烙铁（可选，推荐改用接线端子）或 2.54 mm 接线端子

## 步骤

### 1. 结构件处理

1. 在主动轮外缘粘一圈胶带，增加轮面与轨道的摩擦力
2. 用 M2 × 20 mm 螺丝将主动轮固定到结构件

### 2. 电路连接

| SG90 | ESP32-C3 Super Mini |
|:-----|:--------------------|
| PWM  | GPIO7               |
| VCC  | 5V                  |
| GND  | GND                 |

> - 推荐使用接线端子替代手工焊接（v5.1 迭代结论：端子在可靠性
>   与可拆装性上全面优于焊接）
> - 供电走 ESP32 的 Type-C 口，无需额外电源线

### 3. 装机

1. 将整机挂上方形窗帘轨道
2. 在结构件下方挂钩挂一个塑料袋，放入配重（如矿泉水）压紧主动轮
3. 沿轨道手动推拉整机，确认行走顺畅、轮面无打滑

### 4. 烧录固件

按需选择一套固件（二选一）：

- **ESPHome 版**：适合已有 Home Assistant 的用户，见
  [firmware/esphome/](../firmware/esphome/) 与 README 中的「固件方案选型」
- **Arduino BLE 版**：适合无网关、纯本地控制场景，见
  [firmware/arduino/](../firmware/arduino/) 与 [ble-protocol.md](ble-protocol.md)

## 遮光提示

ESP32-C3 SuperMini 板载电源指示灯在夜间会造成光污染，建议：

- 使用深色耗材打印，或
- 提前用遮光胶带贴住 LED

## 常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 整机推不动窗帘 | 配重不足 / 胶带磨损 → 加配重、换胶带；确认用的是小直径主动轮（v5.2 已内置） |
| 舵机发烫严重 | 长时间堵转 → 减小行程时长，检查是否用了 180° 版舵机 |
| BLE 连接后无响应 | 检查指令格式（详见 [ble-protocol.md](ble-protocol.md)），日志见串口 115200 baud |
| 位置漂移 | 360° 舵机是速度控制而非位置控制，行程由时长近似，必要时微调 travel 时长 |
