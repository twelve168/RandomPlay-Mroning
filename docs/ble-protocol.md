# BLE 控制协议（Arduino 固件）

Arduino 固件（`firmware/arduino/`）通过 BLE GATT 与外界通信，无网关、
无 Wi-Fi，适合纯本地/低功耗场景。

## GATT 结构

| 项目 | 值 |
|------|-----|
| 设备名 | `RandomPlay-Mroning` |
| Service UUID | `4FAFC201-1FB5-459E-8FCC-C5C9C331914B` |
| Characteristic UUID | `BEB5483E-36E1-4688-B7F5-EA07361B26A8` |
| 属性 | Read / Write / Notify |

调试阶段推荐使用 [nRF Connect](https://play.google.com/store/apps/details?id=no.nordicsemi.android.mcp)
连接并手写指令验证。

## 角度语义（360° 连续舵机）

| 角度 | 行为 |
|------|------|
| `< 90°` | 顺时针旋转，越趋近 0° 转速越快 |
| `= 90°` | 完全静止（中位） |
| `> 90°` | 逆时针旋转，越趋近 180° 转速越快 |

## 指令集

所有指令均为 **ASCII 文本**，写入 Characteristic 即触发；大小写不敏感。

### `R` — 即时旋转（到期自动归中）

```
R<角度> <持续时间ms>
```

示例：`R180 5000` → 逆时针全速旋转 5000 ms，随后自动回到 90° 停止。

### `D` — 持续保持（不归中）

```
D<角度>
```

示例：`D180` → 持续逆时针全速旋转，直到收到其他指令。会取消未到期的
自动归中状态。

### `M` — 注册单次定时任务

```
M<HHMM> <角度> <持续时间ms>
```

示例：`M1145 180 5000` → 下一个 11:45 执行"逆时针全速 5000 ms"。

- 任务为**一次性**，触发后自动销毁，次日不再执行
- 最多 10 个并发任务（槽位制，写满后新任务被丢弃）
- 依赖 RTC：请先通过 `T` 指令校准时间

### `S` — 删除定时任务

```
S<HHMM>
```

示例：`S1145` → 删除所有触发时间为 11:45 的任务。

### `T` — RTC 时间校准

```
T<YYMMDDHHMM>
```

示例：`T2603261145` → 校准为 2026-03-26 11:45。

> 设备掉电后 RTC 丢失，需重新校准；ESPHome 版固件无此问题（NTP 自动对时）。

## 设计说明

- **回调内不阻塞**：BLE 写入回调只更新状态机变量，归中判定放在主循环
  `millis()` 比较中完成，避免阻塞 BLE 栈。
- **分钟级扫描**：定时任务每分钟检测一次分钟跳变，避免忙轮询。
- **单次语义**：M 指令刻意设计为一次性而非每日重复——重复调度交给
  上层（手机自动化 / Tasker / HA scheduler）更灵活。
